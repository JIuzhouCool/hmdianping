## 3. 仓库脱敏说明

为了避免泄露敏感信息，本仓库做了以下处理（包含 Git 历史）：

- 数据库、Redis 等连接配置中的公网 IP、账号、口令全部移除/替换为本地地址或环境变量占位。
- `src/main/resources/db/hmdp.sql` 中的测试手机号已替换为示例值（非真实个人号码）。
- 增加 `.env.example` 并在 `.gitignore` 中忽略 `.env`，避免将本地密钥误提交。

如果你需要运行本项目：

- 复制 `.env.example` 为 `.env` 并填入你自己的本地配置
- 或直接在系统环境变量里设置 `HMDP_*` 前缀的变量
